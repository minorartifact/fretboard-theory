# Neckwise

An interactive music-theory visualizer for guitarists. Explore scales, chord tones, intervals, voicings, and progressions directly on the fretboard.

**[Open the app](https://minorartifact.github.io/fretboard-theory/)**

Best viewed on desktop; tablets should work too.

## Features

- Interactive fretboard with multiple tunings and position windows
- Scales, modes, chord qualities, intervals, and note identification
- Circle of fifths and thirds
- Chord progression builder with playback, BPM, looping, and metronome
- Guitar-like Web Audio synthesis
- Fullscreen and jam views
- Shareable URLs and locally saved progressions

Free, client-side, and requires no account.

## Development

```bash
npm install
npm run dev
```

```bash
npm run test:run
npm run build
npm run lint
```
